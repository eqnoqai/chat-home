Explain how sorting algorithms work
Sorting algorithms arrange data in order. Bubble Sort compares adjacent elements and swaps them. Merge Sort splits lists in half recursively — much faster. Here's a quick example:
def bubble_sort(arr): for i in range(len(arr)): for j in range(len(arr)-i-1): if arr[j] > arr[j+1]: arr[j], arr[j+1] = arr[j+1], arr[j]
